GDriveSync · 시행일 2026-10-21

1. 개요

GDriveSync(이하 "앱")는 개발자 본인이 자신의 Google Drive 데이터를 본인 소유의 다른 Google Drive 계정으로 백업하기 위해 사용하는 개인용 도구입니다. 앱은 개발자 본인의 PC에서만 실행되며, 별도의 서버를 운영하지 않습니다.

2. 접근하는 Google 사용자 데이터

  • Google Drive 파일 및 폴더의 내용과 메타데이터(이름, 크기, 수정 시각, 폴더 구조)
  • OAuth 인증 토큰 (Google 계정 비밀번호는 앱이 다루지 않습니다)

3. 데이터 사용 목적

위 데이터는 사용자가 지정한 원본 폴더의 파일을 같은 사용자의 Google Drive 백업 폴더로 복사하는 용도로만 사용됩니다. 파일 복사는 Google Drive API의 서버 측 복사로 Google 인프라 안에서 이루어집니다.

4. 데이터 저장 및 공유

  • 앱은 Google 사용자 데이터를 개발자 또는 제3자의 서버로 전송하거나 저장하지 않습니다.
  • OAuth 토큰은 사용자 본인 PC의 rclone 설정 파일에만 저장됩니다.
  • 실행 로그(파일 이름, 처리 결과)는 사용자 본인 PC에만 저장됩니다.
  • Google 사용자 데이터를 판매하거나, 광고에 이용하거나, 제3자와 공유하지 않습니다.
  • Google 사용자 데이터를 AI/ML 모델 학습에 사용하지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 준수합니다.

6. 접근 권한 철회 및 데이터 삭제

사용자는 언제든지 Google 계정 → 타사 앱 및 서비스에서 앱의 접근 권한을 철회할 수 있습니다. 로컬에 저장된 토큰과 로그는 rclone 설정에서 해당 원격을 삭제하고 로그 파일을 지우면 모두 삭제됩니다.

7. English summary

GDriveSync is a personal tool that copies the user's own Google Drive files to another Google Drive account owned by the same user. It runs only on the user's computer. Google user data is never transmitted to or stored on any developer or third-party server, never sold, never used for advertising, and never used to train AI/ML models. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
