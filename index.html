GDriveSync

Personal Google Drive backup tool

Purpose of GDriveSync

GDriveSync backs up files from one Google Drive folder to another Google Drive account owned by the same person. It runs on a schedule (every few hours) so that the owner always has an up-to-date copy of their documents in a second account.

GDriveSync is a personal, single-user application used only by its developer. It is not offered as a public service, has no user sign-up, and does not require logging in to this website.

How it works

  • The owner shares a source folder with their backup Google account.
  • GDriveSync, running locally on the owner's own computer with rclone, signs in to the backup account with Google OAuth.
  • It uses the Google Drive API to list changed files in the source folder and copy them (server-side copy) into a backup folder in the same account. Previous versions are kept in a separate folder.

How GDriveSync uses Google user data

GDriveSync requests access to Google Drive only to read the files in the folder the owner selected and to create backup copies in the owner's own Drive. Google user data is never sent to or stored on any external server, never shared with third parties, and never used for advertising or AI/ML model training. See the Privacy Policy for details.
