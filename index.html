GDriveSync

개인용 Google Drive 백업 도구 · Personal Google Drive backup tool

소개

GDriveSync는 개발자 본인이 자신의 Google Drive 폴더를 같은 사람이 소유한 다른 Google Drive 계정으로 주기적으로 백업하기 위해 만든 개인용 도구입니다. 개발자 본인의 PC에서 rclone을 이용해 실행되며, Google Drive API의 서버 측 복사 기능으로 파일을 복사합니다.

이 도구는 공개 서비스가 아니며, 다른 사용자를 대상으로 제공되지 않습니다.

About

GDriveSync is a personal, single-user tool that periodically backs up a Google Drive folder to another Google Drive account owned by the same person. It runs locally on the developer's own computer using rclone and the Google Drive API (server-side copy). It is not a public service.

Google 사용자 데이터 사용

이 앱은 Google Drive API를 통해 사용자가 지정한 폴더의 파일과 메타데이터를 읽고, 같은 사용자의 Drive에 사본을 생성합니다. 데이터는 외부 서버로 전송·저장되지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.
